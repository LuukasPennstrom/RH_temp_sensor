This repo is for the code for University of Helsinki Temp/RH sensors using AHT20-F Temp/RH sensor with Adafruit Feather STM32F405 Express along with Adafruit Feather M0 Adalogger.
The code will be updated if I find bugs, or someone else reports them and I get to around fixing them. Otherwise I'll just leave this here, so other people can use it as well.
